**Avaliação Prática 1 - Tailwind CSS**

Atividade realizada na UC de Programação Front-End. O objetivo da atividade consistia em pegar um projeto já estruturado e alterar a forma de estilização, migrando do CSS tradicional para o Tailwind CSS.

Além da refatoração visual, também foram implementadas 5 funcionalidades diferentes utilizando manipulação de DOM com JavaScript.

O projeto apresenta a interface inicial de uma plataforma genérica focada na recomendação e consultoria de imóveis (Homey).

**Tecnologias utilizadas**

* HTML
* Tailwind CSS
* JavaScript (DOM)

Funcionalidades e Manipulações de DOM

Visualização da interface principal de imóveis.

Interação de clique no menu mobile exibindo um alerta em tela (Feedback visual).

Barra de pesquisa com simulação de carregamento (Mudança de cor e texto do botão através do JS).

Botão "Start Searching" configurado para fazer a rolagem da página de volta para o topo.

Entrada de dados na seção de newsletter que cria e insere uma mensagem de sucesso diretamente no HTML.

Atualização automática do ano atual nos direitos autorais do rodapé.

Como rodar o projeto

Por ser um projeto puramente estático, não é necessária nenhuma instalação. Basta baixar os arquivos, extrair e abrir o arquivo index.html em qualquer navegador.
